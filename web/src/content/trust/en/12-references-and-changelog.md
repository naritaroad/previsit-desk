## Glossary

| Term | Meaning here |
|---|---|
| Pre-visit intake | Questions before a visit about the complaint, its course, history, medicines and allergies |
| Red flag | A description that calls for immediate care, decided by rules |
| Output check | The pattern check on a model reply before it is sent |
| Refillable prescription (慢箋) | A continuous prescription for chronic disease |
| Refill booking | Collecting the next fill of an existing refillable prescription |
| Renewal request | Asking a physician to consider another refillable prescription; not itself a prescription |
| Protocol engine | The code that sorts renewal requests into five results by rule |
| Oversight phase | A stage defined by how much a physician reviews; phase 1 is everything |
| Ticket | An item that needs a member of staff |
| Automation bias | Looking or thinking less because the system gave an answer |
| Hazard log | A table of possible harms, controls and remaining risk |
| Run | The processing triggered by one message, possibly with several model calls |
| S, O, A, P | The subjective, objective, assessment and plan parts of a note |
