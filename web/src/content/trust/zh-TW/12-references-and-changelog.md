## 名詞

| 名詞 | 在這裡的意思 |
|---|---|
| 預問診 | 看診前用問答蒐集主訴、病程、病史、用藥與過敏 |
| 紅旗 | 需要立刻就醫的描述，由規則判斷 |
| 輸出檢查 | 模型回覆送出前的樣式檢查 |
| 慢箋 | 慢性病連續處方箋 |
| 領藥預約（refill） | 用既有慢箋領下一次藥 |
| 續開申請（renewal） | 請醫師考慮再開一張慢箋，本身不是處方 |
| 協定引擎 | 依規則把續開申請分成五種結果的程式 |
| 監督階段 | 醫師審閱比例的階段；第 1 階段是全部審 |
| 轉交單 | 需要醫事人員處理的一筆待辦 |
| 自動化偏誤 | 因為系統給了答案而少看、少想 |
| 危害紀錄 | 列出可能傷害、控制與殘餘風險的表 |
| 回合（run） | 一則訊息引發的一次處理，可能含多次模型呼叫 |
| S、O、A、P | 病歷的主觀、客觀、評估、計畫四部分 |
